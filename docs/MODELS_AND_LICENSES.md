# Models, datasets and licences

**Nothing is bundled or downloaded.** Veya's colour suggestion uses Pillow only, and outfit ranking is rule-based.

I did **not** verify licences of any external model or dataset while building this (no research was performed), so the
list below are *candidates to evaluate*, not endorsements. Before using any of them, read the current licence on the official
repository/model card and check commercial-use, redistribution and attribution terms yourself.

| Candidate | Use | What to check |
|---|---|---|
| FashionCLIP (model on Hugging Face) | garment embeddings, zero-shot category/attribute labels, similarity | Model-card licence and training-data terms; CLIP-derived weights; download size (hundreds of MB) |
| Fashionpedia | garment segmentation/attributes research | Dataset licence and image-source terms; may restrict use of the images |
| DeepFashion | fashion research dataset | Typically research/non-commercial terms; do not assume commercial use is allowed; do not redistribute |
| Generic CLIP/OpenCLIP | zero-shot labels | Weight licence of the exact checkpoint |

Rules for this project: never ship datasets or weights in the ZIP; tell the user before any download (size, licence, hardware);
keep predictions labelled as "suggested" until the user confirms; don't publish accuracy claims without measuring on your own data.
Python dependencies (FastAPI, Uvicorn, python-multipart, Pillow, httpx, pytest) are open-source packages with permissive licences; confirm in each package's metadata.
Demo images are original illustrations generated by `backend/app/demo.py`.
